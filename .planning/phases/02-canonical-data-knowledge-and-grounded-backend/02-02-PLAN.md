<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Offline source snapshot -> pipeline normalizer | Source shape, provenance, and synthetic claims may be malformed or misleading. |
| Pipeline output -> bulk upsert | Natural keys and derived fields determine whether records duplicate or overwrite. |
| Pipeline code -> external government host | Ingestion-only egress must never become request-time runtime egress. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-02-05 | Tampering | source fingerprints/natural keys | high | mitigate | Canonical record hashes, explicit natural keys, stable surrogate IDs, and duplicate-source tests. |
| T-02-06 | Repudiation | ingest reports | medium | mitigate | Persist run mode, source identity/version, fingerprints, failures, and loaded/skipped counts. |
| T-02-07 | Information Disclosure | imported KaushalVani vocabulary | high | mitigate | Import only mapped structured fields; preserve synthetic/provenance labels and do not import runtime/auth/PII assumptions. |
| T-02-08 | Denial of Service | ingestion retries/failures | medium | mitigate | Bounded offline inputs, explicit failure status, rate limiting for pipeline fetches, and no request-time fetch. |
| T-02-SC | Tampering | seed/snapshot supply chain | high | mitigate | Stable local hashes and source snapshot manifest; no new package installation required. |
</threat_model>
