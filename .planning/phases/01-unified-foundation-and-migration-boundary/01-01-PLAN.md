## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser/BFF -> FastAPI | Untrusted client requests cross into the canonical API and session state machine. |
| FastAPI -> speech providers | Server-side provider calls cross into external services and must carry no client-held secrets. |
| KaushalVani reference source -> canonical model | Reviewed source concepts cross into canonical IDs and must not import fabricated facts or a second runtime. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-01 | Tampering | API prefix and route registration | high | mitigate | One versioned router policy and contract smoke tests prevent clients from silently selecting a duplicate authority. |
| T-01-02 | Information Disclosure | provider configuration and browser BFF | high | mitigate | Keep provider credentials in typed server settings and assert client code contains only BFF paths. |
| T-01-03 | Tampering | KaushalVani migration map | high | mitigate | Map only canonical IDs/source payloads and explicitly reject generated QP, distance, salary, and fallback entities. |
| T-01-SC | Tampering | source/runtime selection | high | mitigate | No package installation is planned; tests assert the active authority is AVSAR FastAPI and not KaushalVani services. |
</threat_model>
