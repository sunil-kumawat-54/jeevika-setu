<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Android browser/app -> canonical API | Untrusted device audio, text, and offline actions cross into the FastAPI contract. |
| Service worker cache -> beneficiary session | Cached browser artifacts could otherwise replay or duplicate state-changing turns. |
| KaushalVani concepts -> canonical records | Reference vocabulary can introduce PII, fabricated facts, or incompatible IDs if not reviewed. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-01-06 | Tampering | service worker and offline requests | high | mitigate | Keep non-GET requests network-only, test worker behavior, and reserve outbox sync for explicit idempotent draft operations. |
| T-01-07 | Information Disclosure | imported beneficiary fields | high | mitigate | Map only consented/minimal fields, keep organization visibility out of this client gate, and preserve server-side RBAC ownership. |
| T-01-08 | Spoofing | platform decision evidence | medium | mitigate | Require exact device/browser/AT matrix and reproducible contract probe before selecting Flutter or PWA. |
| T-01-SC | Tampering | client dependency choice | medium | accept | No new package is planned; the gate accepts existing AVSAR browser evidence and defers native dependencies until a documented material failure. |
</threat_model>
